🎤 AI-powered platform to practice job interviews with real-time feedback and voice interaction.
🧠 Overview

Prepwise is an AI-powered mock interview system that helps users prepare for technical and behavioral interviews by talking with a voice-based AI interviewer.

It generates questions based on job role and tech stack, listens to your responses, evaluates them using AI, and provides clear feedback — helping users improve communication, confidence, and technical clarity.

This project demonstrates:

AI + Web integration

Real-time speech interaction

Firebase authentication & database

Secure environment variable handling

Modern full-stack architecture

⚙️ Tech Stack
Category	Tools Used
Frontend	Next.js, TypeScript, TailwindCSS, shadcn/ui
Backend	Firebase Auth + Firestore
AI Services	Vapi Voice AI, Google Gemini API
Others	Zustand, Zod Validation, Node/npm
🔋 Features

🎙 AI Voice Interviewer — speak naturally like a real interview

🧠 AI-Generated Questions based on role, level, and tech stack

📊 Performance Scoring & Feedback

🔐 Secure Firebase Authentication (Login/Signup)

📁 Dashboard to store past interview sessions

📱 Responsive UI & smooth animations

🚀 Getting Started
1️⃣ Clone the project
git clone https://github.com/MohammedAfzanPasha15/my-ai-project.git
cd my-ai-project

2️⃣ Install dependencies
npm install

3️⃣ Setup Environment Variables

Create a .env.local file in the root folder:

NEXT_PUBLIC_VAPI_WEB_TOKEN=
NEXT_PUBLIC_VAPI_WORKFLOW_ID=

GOOGLE_GENERATIVE_AI_API_KEY=

NEXT_PUBLIC_FIREBASE_API_KEY=
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=
NEXT_PUBLIC_FIREBASE_PROJECT_ID=
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=
NEXT_PUBLIC_FIREBASE_APP_ID=


⚠️ Keep these values private. Never commit or share .env.local.

4️⃣ Run Project
npm run dev


Open 👉 http://localhost:3000
