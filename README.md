## 🤖 AI MODELS — DUAL BRAIN ARCHITECTURE

### 🧠 Model 1: Human & Helmet Detection

* Detects human presence
* Identifies helmet usage (identity hiding)
* Flags abnormal posture or movement

### 🔫 Model 2: Weapon Detection

* Knife detection
* Gun detection
* Immediate high‑risk trigger

> **Why two models?**
> Separation improves accuracy, safety, and scalability.

## ▶️ HOW TO RUN THE PROJECT (STEP‑BY‑STEP)

### 🔹 1️⃣ Clone the Repository

```bash
git clone https://github.com/MohammedAfzanPasha15/Detection-of-suspicious-activity-in-ATM-using-deep-learning.git
cd ATM-AI-Security-System
```

---

### 🔹 2️⃣ Backend Setup (Python)

Create virtual environment:

```bash
python -m venv .venv
.venv\Scripts\activate   # Windows
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run AI surveillance:

```bash
python live_camera.py
```

📷 Webcam / camera required

---

### 🔹 3️⃣ Frontend Setup (React Dashboard)

```bash
cd frontend
npm install
npm run dev
```

Frontend runs on:

```
http://localhost:5173
```

---

### 🔹 4️⃣ Backend API (if used)

```bash
cd backend
python app.py   # or main backend file
```
